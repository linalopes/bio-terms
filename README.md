# BioArt Map

An interactive visualization of BioArt projects and resources around the world.

## Overview

This project creates an interactive map showing BioArt-related content globally. Each point on the map represents a country with BioArt activities, with the following features:

- Interactive markers showing the number of entries per country
- Popup information with country details and data preview
- Filterable data table below the map
- Summary statistics of total entries and date ranges

## Technical Stack

- **Frontend Framework**: Svelte + Vite
- **Mapping**: Mapbox GL JS
- **Data Visualization**: D3.js
- **Styling**: Custom CSS variables with a purple/turquoise theme
